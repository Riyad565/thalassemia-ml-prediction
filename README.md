# Thalassemia Prediction Model

A machine learning project to predict thalassemia type in patients
using the UCI Heart Disease dataset.

## Skills Used
- Data cleaning and preprocessing
- Exploratory data analysis and visualisation
- Classical ML models: KNN, Naive Bayes, Logistic Regression, SVM
- TensorFlow Neural Network (95% accuracy)

## Based On
- freeCodeCamp: Machine Learning for Everybody (Kylie Ying)
- freeCodeCamp: Python TensorFlow for Machine Learning (Kylie Ying)

## Dataset
UCI Heart Disease Dataset from Kaggle

## Results
| Model | Accuracy |
|---|---|
| KNN | 75.00% |
| Naive Bayes | 70.10% |
| Logistic Regression | 63.73% |
| SVM | 86.76% |
| Neural Network | 94.61% |

The TensorFlow Neural Network outperformed all classical machine learning 
models, achieving the highest accuracy of 94.61%. The Support Vector Machine 
was the best performing classical model at 86.76%, while Logistic Regression 
struggled the most with the multi-class imbalanced data at 63.73%.
